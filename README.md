# 生日照片蛋糕 · 重要的人

一个奶油粒子组成的生日蛋糕，烛光摇曳、彩屑飘落 —— 身边重要的人的照片围在旁边，点一点，还有惊喜。

在线访问：https://momoprince.github.io/moprince.github.io/

## 本地运行

```bash
npm run dev          # 启动本地预览，默认 http://127.0.0.1:7100/
npm run dev -- --port 8080   # 换端口
```

零依赖：不需要 `npm install`，有 Node.js 就能跑。也可以直接用浏览器打开 `index.html`。

## 换成你自己的人

1. 把照片（jpg / png）复制到 `image/` 文件夹；
2. 打开根目录的 `photos.js`，逐行改 `img`（照片路径）、`name`（称呼）、`note`（点开照片时显示的一句话）；
3. 保存并刷新页面。行数随便加减，蛋糕周围会自动排布。

方形照片效果最好，建议每张不超过 500 KB。背景音乐替换根目录的 `曲1.mp3` 即可（保持同名）。

## 玩法

- **拖动** 旋转蛋糕（手机直接用手指划，上下拖还能调整视角）
- **滚轮** 缩放蛋糕大小
- **点照片** 打开拍立得大图和那句话（Esc 或点空白处关闭）
- **绽放**：整个蛋糕化作漫天星光散开，再点一次聚拢回来
- **音乐**：右上角开关背景音乐（浏览器限制，需手动点一次才会播）
- 右上角可开关自动旋转

## 结构

```
index.html      页面骨架
photos.js       ★ 你的人都在这里改
image/          照片文件夹
曲1.mp3         背景音乐
src/style.css   样式（深夜蓝 + 金色粒子）
src/main.js     粒子蛋糕引擎 + 星空彩屑 + 交互
server.js       零依赖本地服务器（线上 GitHub Pages 不需要它）
```

## 技术

- 纯 HTML/CSS/JS，零依赖；5000+ 发光粒子（离屏精灵 + `lighter` 叠加）组成三层奶油蛋糕 + 摇曳烛火
- 惯性拖拽（Pointer Events，触屏可用）、滚轮缩放、照片卡片轻微浮动
- 「绽放」动画：粒子从蛋糕缓动散开成球状星尘
- Canvas 星空 + 彩色纸屑，尊重 `prefers-reduced-motion`
- 灯箱支持 Esc、点背景、按钮三种关闭方式，焦点可及
